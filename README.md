# TaskMate – Personalised AI Assistant for Daily Task Management

## Project Overview
TaskMate is a university computing project designed to help people organise daily tasks, manage priorities and keep track of deadlines.

## Aim
To develop a simple, user-friendly application that helps people manage their daily routines and improve productivity.

## Objectives
- Add, view, edit and delete tasks.
- Set task priorities and due dates.
- Mark tasks as completed.
- Provide a clear and user-friendly interface.
- Test the application's functionality and usability.

## Proposed Technologies
- Frontend: HTML and CSS
- Backend: Python and Flask
- Database: SQLite
- UI/UX design: Penpot
- Version control: GitHub
